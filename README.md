# Портфолио-резюме
Доброго времени суток!
Данный репозиторий содержит код одностраничного сайта-визитки, созданного для первой практической работы (№1).

## Использованные технологии
- HTML
- CSS
- JavaScript
- Библиотека [cursor-effects](https://tholman.com/cursor-effects/) [ для анимации курсора ]

## Использование ИИ-помощника
- **Инструмент:** DeepSeek
- **Задача:** Прототипирование структуры HTML и написание базовых стилей CSS с учетом требования Mobile First.
- **Существенный запрос:** "Создай структуру одностраничного сайта-резюме с семантическими тегами, мобильным меню-бургером и подвалом, содержащим информацию об использованном ИИ и JS-функционале".
- **Результат проверки:** ИИ предоставил рабочий каркас, но стили для мобильного меню требовали доработки под конкретный дизайн.
- **Самостоятельные исправления:** Вручную были настроены медиа-запросы (`@media (min-width: 768px)`), подобрана цветовая схема, отступы, а также были доработаны JavaScript-коды. Помимо этого вручную была подключена сторонняя библиотека для эффекта курсора (ghost). Была настроена секция с галереей (выход за пределы контейнера через `width: 100vw; margin-left: calc(-50vw + 50%)` )
